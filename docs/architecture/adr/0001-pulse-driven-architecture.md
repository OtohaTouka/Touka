# ADR-0001: 脈衝驅動架構 (Pulse-Driven Architecture)

## 狀態
已接受 (Accepted)

## 日期
2026-04-12

## 上下文 (Context)
在早期的系統設計中，排程邏輯（心跳）與執行邏輯（代理人大腦）是高度耦合的。這導致了以下問題：
1. **資源競爭**：排程器與執行器在同一進程中競爭 CPU 與 IO 資源。
2. **擴展性受限**：難以獨立升級或重啟特定組件而不影響整體。
3. **邏輯混亂**：長生命週期的任務容易阻塞心跳檢測。

## 決策 (Decision)
實施「脈衝驅動架構」，將系統拆分為兩個核心組件：
1. **ToukaHeartbeat (Port 8082)**：獨立的「智慧節律器」，負責時間權威、任務排程與脈衝強度決策。
2. **ToukaProxy (Port 8000)**：純粹的「執行大腦」，僅接收 `/awaken` 指令並執行序列化的多脈衝循環。

## 後果 (Consequences)
- **優點**：
  - 組件間高度解耦，提升了系統韌性。
  - 支援長時間背景任務而不影響系統心跳穩定性。
  - 清晰的職責分工（排程 vs 執行）。
- **缺點**：
  - 增加了組件間通訊（HTTP/Internal）的開銷。
  - 需要維護兩套獨立的服務配置。

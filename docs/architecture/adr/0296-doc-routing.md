# ADR-0296：規則與交班依路徑分流

- 狀態：✅ 已實作（PR 1 交班拆檔；PR 2 規則分流、路徑腳本、Guard #46；PR 3 再搬禁令 67）。一頁計畫與上限數字由維護者核准。
- 日期：2026-11-04
- 決策者：維護者
- 相關：ADR-0243（禁令 63，腳本不載入專案程式）。
- 影響範圍：新增 `scripts/applicable_rules.py`、`scripts/guard_doc_routing.py`、`tests/lint/test_doc_routing_guard.py`、`docs/rules/`、`docs/dev-environment.md`、`docs/handover/`；修改 `AGENTS.md`、`HANDOVER.md`、`scripts/guard_all.py`。規則內容、禁令編號與鎖住區段不變，產品程式不動。

## 背景

`AGENTS.md` 約 88 KB、`HANDOVER.md` 約 115 KB，每個對話都要帶著，但大部分內容只和特定路徑有關。Codex 只讀規則檔前 32 KiB，舊檔的禁令清單排在 §1～§17 後面，讀不到。子資料夾的規則檔只在讀到那個資料夾的檔案時才載入，附加目錄不載入，不能靠它分流。

## 決定

1. **分類**：看「改了哪裡」的規則綁路徑，全文搬走；看「加了什麼」的（新增端點、HTTP 客戶端、子程序、路徑字串、時間 API）算全系統，全文留著。例外由維護者決定：禁令 8、11、37 有靜態檢查才搬全文，摘要寫明躲過檢查仍算違規；安全相關的 §2、禁令 60、64、65、66、68 也搬全文。審查發現路徑太窄，後來把這些規則的路徑放寬到整個 Proxy，加上審批卡、IDE 核准與隔離設定頁。路徑寧寬勿窄：寬了只是多讀一點，窄了規則就讀不到。
2. **每條規則只有一份全文**：`AGENTS.md` 保留禁令 1..N 每條一行、順序與編號不變。全文搬走的那一行是一句摘要加 `全文：docs/rules/x.md`，全文放第一個模組的規則檔。§1～§17 保留同名小節。
3. **資料只有兩處**：`AGENTS.md` 的標籤與 `docs/rules/modules.json`。不另外維護禁令索引。
4. **禁令清單排到 §1～§17 前面**，最後一條落在前 32,768 位元組內。
5. **`scripts/applicable_rules.py`**：只用標準函式庫。給路徑（可以是資料夾）或看這次改動，列出適用的規則與交班檔。認不出的路徑要求讀全部；算不出比對基準就失敗。開工前、交付前、審查時各跑一次。
6. **Guard #46 `scripts/guard_doc_routing.py`**：標籤、模組、全文的位置與份數、孤兒全文、規則只剩摘要（暫時例外列在 `inline_rules`）、路徑空白或對不到標到的模組、認不出的檔案、對不到檔案的 glob、最後一條禁令的位置，不符就失敗。規則全文點名的檔案要在它的路徑裡，由測試核對。
7. **大小上限只提醒**：`AGENTS.md` 40,000、`HANDOVER.md` 10,240 位元組，是 Touka 現在這個規模量出來的數字。提醒出現時再決定繼續拆或調高。32,768 是 Codex 讀得到的範圍，超過就失敗。
8. **交班分三層**：`HANDOVER.md` 只放總覽，`docs/handover/<模組>.md` 放還要留意的事，舊內容一字不改存進 `docs/changelog/handover-archive-2026-11.md`。
9. **和舊文件的比對只做一次**：拆分時用不進 repo 的腳本逐行比對。之後沒有舊文件可比，repo 裡只留一致性守衛。

## 碰不到的地方

- 守衛驗不到代理人有沒有讀，也驗不到規則文字：全文被砍短、摘要寫得不準，和分流前一樣靠 PR 審查。不存每條規則的雜湊，規則常改，每次更新也擋不住有心的人。
- 規則文字沒點名、實際碰得到的檔案，靠審查時有人想到。
- Codex 讀得到全部禁令，但清單之後的全系統小節大多讀不到，`AGENTS.md` 在清單開頭提醒要另外讀完。
- 工具與系統說明佔的開場量這次碰不到。

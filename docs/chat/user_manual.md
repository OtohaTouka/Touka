# Touka (燈火) 控制台說明文件

本文件介紹 **ToukaChat** 的核心功能與操作流程。

## 1. 介面導覽

ToukaChat 提供了一個現代化的儀表板，用於管理代理人的靈魂與系統狀態：

- **Chat Lobby (聊天大廳)**: 支援多模態圖片輸入與 **@Mentions** 檔案標記的對話介面。
  - **樹狀歷史 (Tree History)**: 每個對話點都支持分叉。若您對 AI 的回答不滿意，可以點擊「編輯」訊息，系統會自動建立新的對話分支。
- **Agent Editor (設計工坊)**: 即 **ToukaIDE** 模式，包含 PTY 終端機、多檔案 Composer 與代碼編輯器。
- **Soul Core (靈魂核心)**: 編輯代理人靈魂的性格 (Persona)、推理參數與工具權限。
- **Pulse (系統脈動)**: 監看即時日誌、效能數據與工具調用狀態。
- **Vault (記憶金庫)**: 檢索與管理 Agent 的長期向量記憶。

## 2. 核心對話功能

### 💡 如何使用 @Mentions 標記檔案
在任何對話輸入框中打出 **`@`** 字元，即可彈出檔案選單。
*   **精確引用**：選擇檔案後，系統會自動在發送前讀取該檔案內容作為 AI 的上下文。
*   **特殊指令**：可以使用 `@terminal` 引用終端機內容，或 `@codebase` 讓 AI 考慮全專案範圍。

### 🛡️ 對話管理與安全
- **雙重確認機制**：為了防止誤刪，對話刪除採用了優雅的雙重確認流程。
- **同步持久化**：所有的對話管理操作皆會即時同步至後端資料庫。
- **資產主權 (Asset Sovereignty)**：圖片與檔案資產透過 `/v1/outputs/{agent_id}/` 路由動態載入，確保身分隔離。

## 3. 管理靈魂 (Souls)

在 **Soul Core** 頁面，您可以：
1.  **切換靈魂**：從下拉選單選擇不同的靈魂 ID。
2.  **編輯人格**：直接修改 System Prompt。
3.  **調整參數**：調整 Temperature (創意度) 或 Top P。
4.  **工具管理**：勾選該 Agent 允許使用的功能 (如 Web Search, Bash 等)。

## 4. 專業開發模式 (ToukaIDE)

ToukaIDE 整合於控制台中，為開發者提供深度協作能力。

- **工具執行追蹤 (ToolStepTracker)**: 即時顯示 Agent 使用工具的步驟、參數與結果。
- **HITL (Human-in-the-loop) 模式**: 所有對檔案的修改都需經過 Diff 預覽與人工確認後方可套用。
- **YOLO 模式 (You Only Live Once)**: 開啟後，Agent 可自動執行非破壞性的開發操作，提高效率。
- **終端機自動修復**: 自動捕捉終端報錯並讓 AI 協助診斷與修復。

## 5. 系統設定與維護

### 設定頁組織（依功能分組）
設定分頁依功能分為五組，並提供**側邊欄全域搜尋**（打字即可跨分頁尋找設定）：

- **個人**：一般（個人資料、頭像、語言、資料匯出／清空）；外觀（亮／暗／跟隨系統主題、強調色、字級、時間格式 12/24 制、介面密度、對話泡泡樣式、減少動態效果）。
- **模型與供應商**：模型（含每個原生模型的取樣參數）、供應商金鑰、連線。
- **代理人能力**：工具、MCP（含每台伺服器的健康狀態與單台重啟）、技能。
- **對話**：群聊權限、滑動視窗、SNS 機器人。
- **系統管理**（僅管理員）：使用者、安全、環境備份（含加密下載與自動排程）、設定匯入／匯出等。

> 底層採 **OCP 分頁註冊表**（分頁定義集中管理、易擴充）與**領域資料鉤子 (SSOT Hooks)**，確保連線、安全性與 MCP 等設定的資料來源單一。

## 6. 系統健康與背景任務復原 (ADR-0078)

Touka 會主動讓你「看見」異常，而不是默默失敗：

- **🔴 系統降級橫幅 (DegradedBanner)**：若記憶系統（ToukaMemory）未成功載入，側邊欄頂端會出現一條**紅色常駐橫幅**「系統降級運行中…」。此時 Agent 仍可對話，但**長期記憶與部分工具暫時離線**。橫幅跨分頁可見，記憶系統恢復正常後自動消失。
- **⚠️ 上次有 N 個未完成的背景任務**：若 Touka 在執行背景「心跳」任務時被當機或誤關，重新啟動後，系統監控（System）分頁會顯示這則通知，列出哪些代理人的背景任務沒跑完——**它們不會再默默消失**。
- **🔄 一鍵重新觸發**：上述通知中每一筆旁邊都有「重新觸發」按鈕。按下後 Touka 會**接續**那個中斷的任務繼續跑（沿用既有對話歷史，不會洗掉進度）。基於安全，此操作一律以 **Auto 模式**執行（你不在場時不跑指令、不叫審查員）、且只有該代理人的**擁有者**能觸發。

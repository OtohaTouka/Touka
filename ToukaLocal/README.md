# Touka 本機小幫手

讓靈魂在你開放的資料夾裡看檔案、新建文字檔，或提出搬移與刪除清單給你核准。設計與邊界見 [ADR-0311](../docs/architecture/adr/0311-local-helper-for-host-files.md)。

目前只有 Windows，介面只有繁體中文，只用 Python 標準函式庫。

## 安裝

不要從 Touka 資料夾安裝：那個資料夾有掛進容器，代理人寫得到，安裝程式會拒絕。

1. 把 GitHub 上的 repo clone 到 Touka 資料夾以外的地方，例如 `%TEMP%\touka-helper`，切到要安裝的版本，確認 commit 和 GitHub 上顯示的相同。

2. 用 Touka 資料夾以外的 Python 3.12（要有 tkinter，例如 uv 裝的版本，不要用 `.venv`）執行：

   ```bash
   python -I -S ToukaLocal/install.py --touka-folder "D:\Touka"
   ```

   `--touka-folder` 是你放 Touka 的完整路徑。小幫手會記下來，不讓你把它開放出去。

3. 用桌面上的 `ToukaLocal.cmd` 啟動。

程式裝在 `%LOCALAPPDATA%\ToukaLocal\app\`，clone 下來的資料夾之後可以刪掉。

**Touka 升級時如果協議改版，小幫手會顯示版本不符，請用新版本重新跑一次上面的步驟。** 配對和開放的資料夾會保留。

## 配對

Touka 網頁：設定 → 本機小幫手 → 產生配對碼，貼到小幫手視窗按儲存。配對碼只顯示一次。如果 Touka 不是跑在 8000 埠，連接埠也要一起改。

## 開放資料夾

- **只能看**：靈魂可以看檔案清單、讀文字檔。
- **可以改**：另外可以新建資料夾和文字檔（txt、md、log），也可以提出搬移與刪除清單。新建或搬到的名稱不能以點開頭，新取的名稱也不能有全形斜線、全形空白這類容易看錯的字元（搬移時沿用原檔名不受限）。

資料夾要開得窄。靈魂讀到的內容可能被它用上網工具送出去，這條路小幫手擋不到。

小幫手連上了，靈魂卻沒有這個工具時，請看：靈魂有自己的工具清單時要勾選 `local_files`；無痕對話不能用；靈魂還有別的擁有者時也不提供。

這些位置不能開放：系統資料夾、`Program Files`、`AppData`、Touka 資料夾、已經掛進容器的資料夾、使用者資料夾本身、磁碟根目錄、網路磁碟、Git 專案。隨身碟這類不是固定磁碟的位置，和 `.ssh`、`.aws`、`.gnupg` 這些放金鑰的資料夾，也不能開放。

## 核准

搬移和刪除一定要你在小幫手視窗按核准，Touka 的任何模式都跳不過。清單是小幫手自己檢查檔案產生的，代理人的說明可能不準，以清單為準。刪除是丟到回收桶；搬移可以在「最近批次」復原。

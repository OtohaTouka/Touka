# ADR-0004: 物理路徑禁令 (Physical Path Ban - TID251)

## 狀態
已接受 (Accepted)

## 日期
2026-04-23

## 上下文 (Context)
代碼中散落著如 `D:/Touka/data` 或 `/app/data` 的硬編碼路徑。這導致：
1. **環境適應力差**：在 Windows 與 Docker 環境切換時頻繁出錯。
2. **主權洩漏**：Agent 可能透過路徑遍歷（Path Traversal）逃逸出其指定的 Sandbox 範圍。
3. **測試困難**：難以在測試期間重定向所有檔案操作到沙盒目錄。

## 決策 (Decision)
實施嚴格的「物理路徑禁令 (TID251)」。
1. 嚴禁在業務代碼中出現任何絕對路徑字串。
2. 所有路徑獲取必須透過 `ResourceManager` 或全域配置 `AppDataDir` 動態解析。
3. 部署 Ruff 法律進行自動化監督。

## 後果 (Consequences)
- **優點**：
  - **環境無關性**：同一份代碼可無縫在 Windows、Docker 或開發環境運行。
  - **安全性提升**：強制性的路徑解析通道使得權限校驗更容易實施。
  - **測試穩定性**：可以透過環境變數一鍵重定向所有測試資料。
- **缺點**：
  - 開發者需要學習新的路徑獲取模式，不再能直觀地操作檔案。

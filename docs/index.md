## 🚀 專案概述

**Touka Proxy** 是一個高性能、具備長期記憶能力的 AI 代理中間層。它能將標準的 OpenAI 請求轉發至 Anthropic (Claude)、Google (Gemini) 與 xAI (Grok) 模型，並無縫整合多種通訊協議以及一套基於向量資料庫的「大腦」系統。

### ✨ 核心特色

- **❤️ 自主心跳與續命**：整合 `ToukaHeartbeat` 外部調度器，支援自主預算決策。
- **📂 專案管理與主權隔離**：強制實施預設監獄原則，透過 `AgentIdentity` 物件物理鎖定操作路徑。
- **🛡️ 極限防禦與身分憑證化**：全系統 JWT 認證、LDH (本地動態握手) 與策略即程式碼 (PaC)。
- **🧬 ID 歸一化與靈魂保護**：全面移除舊版前綴，實施 L1 級別物理目錄硬保護。
- **📊 依賴主權與合約一致性**：自動化依賴守衛與 OpenAPI 合約同步校驗。
- **🔄 記憶整合與 fail-loud 邊界** ⭐：ToukaMemory 依 ADR-0116 採**整合模式單一部署**，僅以同行程函式庫整合於 ToukaProxy；工具 I/O 透過 `get_resource_proxy()` 取得 Proxy 注入的真實 `ResourceManager`，缺失時拒絕降級並明確失敗。

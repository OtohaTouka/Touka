# Hook 規則

範圍：Hook 引擎與設定、會發事件的程式，以及它們碰到的專案根、檔案動詞、插話、SNS。

從根 `AGENTS.md` 搬來的全文，搬完只在 ⑧ 補上程式已經照做的三個事件名。跑 `python scripts/applicable_rules.py --print-rules` 看這次改動適用哪幾條，不必讀完整份。改規則見 [README](README.md)。

## 禁令

*   **禁令 67（Hook / ADR-0292）**：①hook 只能擋下或要人確認：**嚴禁**採用 `allow`、`updatedInput` 一類放行或改寫的欄位，hook 也**不能**核准審批卡、推翻底線或改寫已核准的參數；PreToolUse 排在政策判定之後，hook 的「要人確認」不送審查員、無人在場直接拒絕，Auto 與 YOLO 都不能代替人；PermissionRequest 只有 `deny` 生效，**不能**代替人核准，卡照樣跳；PermissionDenied、Notification、Stop 只通知，**不能**改結果。②`hooks.json` 只經 `PUT /v1/hooks` 改（人類 admin、revision 比對、CSRF Origin），**嚴禁**放進設定匯出／匯入；代理人用終端讀寫屬底線 F2（http 標頭可能有權杖；檔案動詞與 MCP 不經底線，靠④的專案根限制）。③command hook **嚴禁**經 shell：只以程式＋參數清單經 `execution_broker.spawn_exec` 啟動，事件內容只從標準輸入給，環境不含金鑰；http hook 不跟隨轉址、有逾時與大小上限，標頭照字面送出、不替換環境變數。④參數裡的路徑必須在設定資料夾的 `hooks/`，程式在別處時**嚴禁**指到代理人寫得到的地方（`services/hooks/paths.py`），存檔與每次執行前都檢查，讀不到狀態一律拒絕；一般使用者的專案根**嚴禁**放在 Touka 保護的位置（`isolation/profiles.project_root_reason`），代理人的專案根路上有連結時專案檔案工具一律拒絕（`profiles.has_link`）；代理人的檔案動詞開檔與走訪**嚴禁**跟隨連結（`memory_server/utils/no_follow.py`、`ResourceManager` 的 `*_no_follow` 方法），list、find、grep 不進入連結。⑤回給模型的 hook 輸出一律當資料（`<hook_output>` 區塊或 `hook_output` 鍵，先中和區塊 tag）。⑥hook 自己失敗或逾時不擋動作、但要記在執行紀錄；無痕只記時間、事件與結果；給 hook 的事件內容只放列好的欄位，錯誤文字先遮憑證與路徑，被拒原因只放固定代碼；不等結果的事件一律走 `services/hooks/background.py`（同時執行有上限，超過跳過並留紀錄）。⑦UserPromptSubmit 擋下的內容**嚴禁**換條路進到模型或對話：插話進佇列前也要檢查，SNS 外人訊息被擋下時不寫進對話；hook 執行期間使用者停止時**不得**再送模型或執行工具；工具 hook 也要比對舊工具名稱對應的新名稱。⑧Elicitation 只能拒絕，**嚴禁**採用 `accept`、`content` 替人回答，hook 逾時上限 30 秒（`mrtr.py` 的回合上限要跟著加）；StopFailure、PreCompact、PostCompact、TaskCreated、TaskCompleted、SubagentStop、ConfigChange、HeartbeatStart、HeartbeatStop 只通知，**嚴禁**等 hook 或採用擋下（剪裁不能被拖住、設定一定存得進去、hooks 一定關得掉）；ConfigChange 只在確認存好之後發（備份還原例外：在接受時發），內容**嚴禁**放設定值，新的改狀態路由要在 `test_hook_config_change_security.py` 分類。由 `test_hook_paths_security.py`、`test_project_root_protected_security.py`、`test_file_ops_no_follow_security.py`、`test_hook_runners_security.py`、`test_hook_wiring_security.py`、`test_hook_tool_events_security.py`、`test_hook_lifecycle_events_security.py`、`test_hook_config_change_security.py`、`test_hooks_router_security.py`、`test_interjection_endpoint_security.py`、`test_sns_gateway.py` 執法。（ADR-0292）

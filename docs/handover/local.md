# 本機小幫手交班

範圍：`ToukaLocal/**`：使用者電腦上的小幫手（ADR-0312）。

這份只放這個範圍沒做完、有未解限制、做完還沒部署或要特別操作的事。總覽見 [HANDOVER](../../HANDOVER.md)。

## 現況

- 第一版試行中，只有 Windows。協議改版時，小幫手要重新安裝（`ToukaLocal/README.md`）。
- `ToukaLocal/` 不走 Touka 的 SSOT，各條禁令怎麼適用見 ADR-0312 第 11 點。
- 連結和真檔案只有在 Windows 上才測得到，CI 只有 Linux：改 `ToukaLocal/` 時要在本機跑 `tests/unit/local_helper/`。
- 自動測試沒有真的把檔案丟進回收桶，只在 2026-11-10 人工試過兩次，第二次比對了帶與不帶 `FOF_NO_CONNECTED_ELEMENTS`：帶了只丟清單上的 `a.html`，`a_files` 留著。改 `winapi.RecycleBin` 時要用可拋棄的檔案再試。
- 維護者 2026-11-15 試行過一次，列目錄、新建、搬移、刪除核准、還原都正常。回饋（字糊、AI 看不出有沒有被核准）的第一部分在 2026-11-16 改了：宣告縮放、微軟正黑體、像素跟著放大、關視窗先問、結果與工具說明寫清楚。宣告縮放之後的畫面還要維護者看一次，特別是 200% 縮放下表格列高與欄寬。
- 第二版的「照 Touka 的模式核准」已做（ADR-0317），「從 Touka 設定頁請小幫手開放資料夾」也做了（ADR-0320），一行指令安裝也做了（ADR-0329，小幫手 0.3.0）。
- 一行指令安裝改用 Python 3.14 與 Tk 9.0，字型、縮放與視窗還要維護者在真的電腦上看一次；CI 仍只用 3.12、只跑 Linux。小幫手的檔一改，`install.ps1` 的雜湊清單與 README 那一行都要換（兩個 commit，`scripts/local_helper_pins.py` 印出該有的值）。Python 要重新釘的時機寫在 ADR-0329。
- 開放請求的兩種視窗（能開放、不能開放）、主視窗的停收提示與「現在恢復」，還要維護者在真的電腦上看一次；自動測試在 Windows 本機用真的 Tk 檢查了預設按鈕、核准鍵延遲與權限預設（沒有核對實際的鍵盤焦點），CI 只跑 Linux。
- 照模式核准的卡片清單、主視窗的開關與重新計算、舊配對碼提示，還要維護者在真的電腦上看一次；實際驗證（`test:e2e:real`）沒有能輪詢的假小幫手，卡片清單沒在真的前端跑過。
- 0.4.0 退到背景（ADR-0312 補註 2026-11-24）：自動測試在 Windows 本機用真的 Tk（3.12 的 Tk 8.6 與複本的 3.14.10 Tk 9.0.4）檢查了收起、叫出、最小化浮出與審批視窗照樣顯示；還要維護者在真的電腦上看一次：
  1. 已配對、開機啟動：重開機後只閃一下主控台，沒有主視窗也沒有工作列按鈕；
  2. 在背景時雙擊桌面啟動檔：主視窗到最前面（只閃工作列按鈕也可以，記下來）；
  3. 主視窗開著時再開一次：不跳「已經開著了」；
  4. 按 × 後從 Touka 設定頁送開放請求：視窗照樣跳在最上層；
  5. 在 Touka 重新產生配對碼：主視窗最小化出現在工作列，不搶正在打字的視窗；看完把新的配對碼貼回主視窗按儲存；
  6. 「結束小幫手」：先問、按確定後真的結束，之後再貼安裝指令不會說正在執行；
  7. 從 0.3.0 升級：「啟動」資料夾那份帶 `--background`，桌面那份不帶；
  8. 200% 縮放下新按鈕與說明列的排版。
- 開始功能表沒有入口（要動露出檢查），叫出主視窗靠桌面的 `ToukaLocal.cmd`。Tk 9 似乎內建 `tk systray`，但要經過 `.tk.call`，邊界檢查禁止，沒有用。
- OneDrive 資料夾本身會不會帶雲端佔位屬性沒有實測。如果會，整個 OneDrive 底下都會當連結拒絕，試行時留意。

## 待排小項

- GHCR 舊安裝升級後，新錯誤碼不在播種的 `errors.json` 裡（ADR-0140 ⑥：升級不刷新播種內容），小幫手的失敗路徑會變成 500。只影響這個新功能，和既有的同類問題一起處理。
- 小幫手不驗證連線另一頭是不是真的 Touka（ADR-0312「後果」）；照模式核准的決定靠配對鑰匙蓋章（ADR-0317），讀取與新建仍只靠權杖。
- Python 裝在 Touka 資料夾的上層，又用預設的 `./data` 掛載時，小幫手會判成程式露出而停止服務。方向是安全的，配置也少見；換一個位置的 Python 就能解。

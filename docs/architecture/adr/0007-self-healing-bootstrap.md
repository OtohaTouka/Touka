# ADR-0007: 自癒引導機制 (Self-Healing Bootstrap)

## 狀態
已接受 (Accepted)

## 日期
2026-04-23

## 上下文 (Context)
新環境部署或設定檔意外遺失常導致系統無法啟動。手動複製範例設定檔既繁瑣又容易出錯。

## 決策 (Decision)
實作「自癒引導機制」。啟動時由 `src/core/bootstrap.py` 自動檢查環境變數與必需的 JSON 配置。若發現遺失，則自動從 `.example` 範本恢復。

## 後果 (Consequences)
- **優點**：
  - **開箱即用**：極大降低了新開發者的上手門檻。
  - **系統韌性**：防止了因單一設定檔缺失導致的災難性崩潰。
- **缺點**：
  - 如果使用者刻意刪除某些配置，系統會自動補回，可能造成混淆（除非禁用引導）。

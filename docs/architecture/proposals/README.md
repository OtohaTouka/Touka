# 設計提案（歷史）

這個資料夾收的是 Touka 開發過程中寫下的設計提案與實作計畫。保留下來是為了說明設計脈絡：當時看到什麼問題、比較過哪些做法、為什麼選了現在這一個。

閱讀前請先知道：

- **現況以 ADR 為準。** 提案寫的是當時的狀態與打算，很多內容後來已經改寫、取代或退役。目前的設計與決定請看 [架構決策紀錄（ADR）](../adr/README.md)；多數提案開頭的狀態列會連到對應的 ADR。
- **PR 編號與 commit 指的是開源前的私人歷史。** 公開 repo 從一份快照開始，文中提到的 PR 編號、commit 雜湊與分支，在公開 repo 裡都查不到。
- **單位代號對得到 ADR 的小節。** P8-A、P11、E35 這類代號是當時切分工作的單位名稱，ADR 用同一個代號標示對應的小節，可以拿代號到 ADR 裡搜尋。
- **「原件未入版控」** 指當時的調查紀錄、證據或交接筆記沒有放進 repo，文中只留摘要。
- 文中的「維護者」指 Touka 專案的維護者；`Owner`、owner 指的是產品裡的角色或擁有關係（例如靈魂的 Owner 角色、session 的擁有者），見 [角色模型](../ROLE_MODEL.md)。

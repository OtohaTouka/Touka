    - **修法（分 3 批、全 TDD）**：①`connections.ts` 送出前 `isTokenExpired` → single-flight `refreshAccessToken()`（token 永不過期抵達＝LDH 對 UI 永不觸發；採送出前 exp 檢查而非 401-retry，因 LDH 對過期卡本不回 401）；②`X-New-Auth-Token` **僅未登入採納**（縱深防挾持）；③`identity_router` 刪「本地壞卡當無卡」——帶失效 token 一律 401 `AUTH_INVALID_TOKEN`＝**禁令 60**（LDH 僅留給真正無卡的本機請求）；④`users.json` 升 admin（授權地基暫解，長期正解＝ADR-0132）；⑤無痕旗標「誕生即登記」（`ChatProvider` ref Set，發送旗標＝清單 ∪ 誕生登記，補 wipe 競態下**零殘留閘門失守**的隱私缺口）；⑥`syncSession` 補 `res.ok`——失敗可見化（固定 toast id 防轟炸）；⑦`refreshSessions` 整批覆蓋改 **merge**（後端 persisted 權威、本地僅保 incognito）。三層互為備援（不過期抵達＋抵達也 401＋降級也不採納）。
    - **驗證**：guard_all 38/38、後端 pytest 2717、前端 vitest 971、LDH 冒煙 4/4。詳見 `SECURITY.md` L1–L4。

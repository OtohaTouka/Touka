-   **2026-06-25**: **互動式 React artifact 預覽（ADR-0114，選項 A，純前端）⭐**
    - **背景**：artifact 預覽原本只能渲染純 HTML+inline JS；AI 寫的 React/JSX/TSX 元件不會轉譯/執行（顯示壞掉的標記）。目標是類似 claude.ai 的互動體驗。評估分三層：L1 純 HTML（已有）、**L2 React 真的跑＋離線**、L3 外部庫/CDN/網路。本次做 **L2（選項 A）**；L3 需放寬隔離＋獨立 origin 基礎設施，留待選項 B 另案。
    - **設計**：父層 lazy `@babel/standalone` 把 JSX/TSX 轉成純 JS **字串**（preset-react classic＋typescript＋commonjs），連同**預建 React 19 runtime**（`esbuild` 打 IIFE→gitignore 的 `src/generated/`，因 React 19 無 UMD）注入既有沙箱 iframe（`sandbox="allow-scripts"`、無 same-origin、CSP `connect-src 'none'`）由 React 渲染。iframe 內 `module`/`exports`/`require` shim（`require` 對匯入丟離線錯誤）解析 `export default`/`App`。extractor 偵測 React 訊號→新 `'react'` 型別；完整 HTML 文件仍走 `web`。i18n `artifacts.react.*`。WebRenderer 改吃共用 `sandbox.ts` SSOT（CSP/sandbox/doc builder）。
    - **四安全不變式（測試鎖死）**：①父層絕不執行使用者碼（禁 eval/new Function）②iframe 永不 same-origin ③CSP `connect-src 'none'`、無外部 script ④`</script>` 逸出。
    - **對抗式複審（6 個視角＋懷疑者驗證）**：核心不變式全成立、無逃逸/RCE。據複審加固：CSP 移除 `https:`（img/font/media→`data: blob:`，杜絕遠端 GET beacon；互動 React 會放大為鍵入內容外洩）＋串流期轉譯**防抖 300ms**（消除 O(n²) 主執行緒凍結）＋轉譯 **256KB 上限**＋i18n 訊息亦過 escapeForScript＋顯式 tag type 白名單驗證/正規化＋extractor 用 `match.index`。
    - **實機證明**：以真實 `transpileArtifact`+`buildReactSrcDoc`+生成 runtime 產出 srcdoc 於真瀏覽器載入——JSX 計數器在生產 CSP 下掛載、`onClick` 經 React 19 fiber 觸發、點擊 Count 0→1、零 console 錯誤（互動 React 確證）。
    - **驗證**：`guard_all` **37/37**、vitest **877**（+Option A 29 測：transpile/sandbox/extractor/ReactRenderer/安全靜態掃描）、ESLint/typecheck 乾淨、smoke/pytest 不受影響（純前端）。⚠️限制（文件化）：Tailwind class 不生效、外部庫/網路不可用（L3）、**遠端圖片不載入**（離線）、僅單檔元件。ADR-0114＋adr/README。
    - **背景**：15-tab 分組（5 組分類標題、全部可見）後，維護者反映側邊欄太長，決定：分類標題改為可摺疊，**預設只展開目前所在群組**、其餘收起。
    - **設計**：`SettingsView` 分類標題由唯讀 `<span>` 改為**摺疊開關 `<button>`**（`aria-expanded`＋ChevronDown 旋轉指示）。展開狀態以 `useLocalStorage`（SSOT hook，免裸 localStorage）持久化 `touka_settings_expanded_groups`（存已展開群組 id 陣列）；**目前所在分頁的群組永遠展開（force-show）**，確保選中分頁恆可見。摺疊**僅作用於桌機**（`md:hidden`）——手機維持橫向平鋪、無分類標題、所有分頁照常顯示。搜尋模式整個分頁清單本就隱藏，不受影響。非 admin 只有一組（個人）＝即目前群組＝恆展開。
    - **驗證**：純前端、無新 i18n（用既有 group.label＋aria-expanded 傳達狀態）、無 NOQA 變動（走 useLocalStorage hook）。`guard_all` **37/37**（含 #27 typecheck、#35 ESLint 棘輪、a11y 守衛）；vitest **848**（既有設定測試零回歸；SettingsView 為重供應商整合元件、沿既有慣例不單測，邏輯經審查＋關卡把關）。**剩維護者實機人工驗收。**

# ADR-0301：家標記不算進對話的存檔版本

- 狀態：✅ 已實作。一頁計畫由維護者核准，計畫經兩輪審查。
- 日期：2026-11-06
- 決策者：維護者
- 相關：ADR-0231（對話保存的版本與恢復，本 ADR 修訂它的第 3、8 點）、ADR-0092（滑動視窗剪裁）、ADR-0295（實際驗證）。
- 影響範圍：`ToukaProxy/src/utils/async_db.py`、`src/services/sliding_window_service.py`、`ToukaChat/src/lib/session_persistence.ts`、`src/lib/providers/SessionListProvider.tsx`。

## 背景

對話存檔有一個版本，每次存都要帶上次拿到的版本，對不上就擋，避免舊畫面蓋掉新內容（ADR-0231）。家標記（`is_home`、`home_for_agent`）也算在版本裡，所以回覆還在跑、或剛結束還沒存完時設家、換家、取消家，回覆收尾的保存帶的是舊版本，被擋下，畫面跳「尚未保存」的提示，要按「重新核對」和「僅重試保存」才能繼續。內容不會掉，但每次都要按兩個按鈕。實際驗證「剪裁（聊天）」那條在剛回覆完就設家的那一步偶發紅，也是這個原因。

家標記不需要靠版本保護：已經存在的對話，家標記只由 `set_home` 改（心跳只在還沒有家時，新建一段已經標成家的對話）；一般存檔本來就不寫它（後端 `SessionModel.to_changes` 丟掉這兩欄），而且每次存檔都在同一個交易裡重讀最新的那一列、只改要改的欄位，舊版本存進來也蓋不掉新家。刪除時「家不能刪」、換綁靈魂的檢查，也都是在交易裡看最新的那一列。

## 決定

1. `_session_revision` 計算版本時拿掉家的兩欄。其他欄位（含擁有者、靈魂、範圍版本）、程序代數與刪除重建的代數照舊算進去。帶版本的存檔不能改已存在對話的家欄位（一律擋下），家標記只能經 `set_home` 改：它會先清掉同一個靈魂的舊家，存檔改的話可能變成兩個家。心跳在還沒有家時新建家對話不受影響（那時對話還不存在）。
2. 剪裁只剪家對話。原本靠呼叫的地方先判斷一次，中途換家時靠「版本變了」作罷；版本不含家標記之後，剪裁自己查兩次：
   - 讀檔後（範圍檢查之後、觸發剪裁前的 hook 之前）不是家就不剪，不歸檔、不寫摘要、不觸發 hook。
   - 存回時在同一個交易裡再查一次（`conditional_save_session(require_home=True)`，預設關閉，只有剪裁打開），擋住讀檔之後才取消家或換家的情況。這時已經歸檔、寫過摘要：歸檔的訊息之後真的剪到時不會重複存（舊對話庫同一則訊息只存一次），但白花一次寫摘要的費用，和剪裁存不進去的其他情況一樣。
   - 心跳跑到一半換家：剩下的脈衝繼續寫在原來那段（原本會因版本變了整次記成失敗），結尾的剪裁因為已經不是家而跳過。
3. 畫面：
   - 存檔送出的欄位表拿掉家的兩欄（後端本來就丟掉），比對內容時也不比。外部只改家標記不算內容變動。
   - 設家之後不作廢本機的版本，也不作廢待恢復的版本（「僅重試保存」照樣可用），不必先重讀存檔。
   - 設家前送出、還在路上的保存回來時，家欄位保留設家的結果（`withSavedHome`）：一般保存與排隊的命令、回覆收尾（成功與失敗）、「僅重試保存」。

## 取捨與影響

- 開始回覆前的檢查（`admit_ui_stream`）不再因設家擋下。那一輪提示詞裡的「家對話」內容可能還是設家前的，只影響這一輪，不影響存檔。
- 原頁來不及存完整內容就關掉、之後才設家：以前重新整理時版本不同，不重播、工具步驟補不回來；現在版本相同，重播並補存完整內容（完整內容已經存好時，版本早就不同，本來就不重播）。
- 設家後畫面不重讀存檔，別處改過的內容改由後端用版本擋下（存不進去、留著草稿、跳提示），和其他欄位一樣。
- 版本只是防覆蓋用的記號，不是權限；設家、刪除、換綁的權限檢查都不變。

## 已知限制

- 設家時剛好有讀檔在路上（切對話時的清單重新整理、接回串流前的讀檔、「重新核對」、沒有版本時存檔前的讀檔、新對話出現時的下載），晚回來的舊結果可能讓畫面上的家標記暫時顯示舊的；不會擋存檔（存檔不送也不比家欄位），下次清單重新整理就對了。
- 「家」按鈕在還沒有家時新建的對話：畫面標成家，存檔卻不是家（既有問題，後端一直不收畫面送的家標記），另外處理。
- 剪裁和畫面收尾的保存仍會搶同一個版本（ADR-0295 記的既有問題，路線圖 3c ③），不在這裡修。

## 驗證

- `tests/unit/test_session_home_revision.py`：設家、換家、取消家後舊版本照樣存得進去、新家留著；帶版本的存檔改不了家欄位；舊版本仍刪不掉、換綁不了新家；剪裁讀檔前不是家就不剪、讀檔後換家存不回去；心跳中途換家，脈衝存進原來那段、結尾不剪。
- `tests/unit/test_session_persistence_ordering.py`：直接改家的兩欄版本不變，其他欄位（含範圍版本）照樣讓舊版本失效。
- `ToukaChat/src/lib/__tests__/session_persistence.test.ts`、`src/lib/providers/__tests__/SessionListProvider.syncSession.test.tsx`。
- 實際驗證 `ToukaChat/e2e-real/session-save.spec.ts`：回覆還在跑時設家、換家都不跳提示；把收尾的保存延後、這期間設家，放行後不跳提示，資料夾那一列是新家。
